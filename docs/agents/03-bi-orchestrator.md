# 03 — BI Orchestrator

## Purpose
Coordinate execution across BI services, data sources, and downstream processing components.

## Inputs
- BI query specifications
- Service and data source configuration

## Outputs
- Execution plan and run metadata
- Consolidated BI results
- Error and retry traces
